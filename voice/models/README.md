# Local Voice Models Directory

This directory stores offline ONNX voice checkpoints and configurations for local Piper TTS:
- `en_US-lessac-medium.onnx` (model weights)
- `en_US-lessac-medium.onnx.json` (model phoneme config)

These files can be downloaded automatically or manually from Hugging Face / Piper GitHub releases without requiring any API keys or paid accounts.
The `.gitignore` is pre-configured to ignore binary `.onnx` files while preserving setup instructions.
