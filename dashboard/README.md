# Admin Dashboard (Next.js App Router)

This directory will contain the Next.js 14+ App Router admin dashboard built in Phase 4.

## Features Planned for Phase 4:
- **Bookings Management**: Today's reservations, upcoming bookings, filtering by date/status, direct cancellation.
- **Call Logs & Transcripts**: Detailed call logs with audio durations, outcomes, and full chronological conversation transcripts.
- **Unanswered Questions**: Real-time triage view for questions the voice assistant could not answer from FAQs.
- **Business Settings**: Visual editor for opening hours, capacity per table, slot duration, and FAQs.
- **Real-Time Updates**: Auto-refresh polling for newly booked reservations and incoming calls.
